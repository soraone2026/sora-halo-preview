# Sora One · 曦環城入口 A 版試玩預覽

直接開啟：**https://soraone2026.github.io/sora-halo-preview/**

- 這是 Sora One 遊戲的一段試玩預覽（單一 HTML 檔，`index.html`）。不需要登入，也不需要伺服器；圖片和 three.js 都已內嵌，可以離線開。
- 存檔只在你自己的瀏覽器裡，從 1 B 開始；頁面上方「↺ 重玩這段」連按兩次可以重來。和正式遊戲、其他人的存檔完全分開。
- 試玩範圍：點上方「世界」→ 星際城市「曦環城」。
- 手機和電腦都可以玩。第一次開啟有幾秒的進場動畫和 3D 載入。

## B 版（2026-11-22）
直接開啟：**https://soraone2026.github.io/sora-halo-preview/b/**

- 捏完臉後，二樓臥室出現站務員的委託 →〔去車站看看〕她自己走去小鎮車站（或〔先逛房間〕，委託縮成側邊的「站務員的信」）→ 站務員開口、修站名燈 → 修復手帳。
- 修好燈後可以〔去月台搭車 · 3 B〕到奧蕾莉亞城區（廣場、圖書館、會響的晶石、館員的三題）。
- 試玩版沒有伺服器：車票、寶石、小遊戲入口由 `b/city/playtest-api.js` 在你的瀏覽器裡代答；朋友在線、邀請、寄明信片這版沒有。
- 存檔一樣只在你自己的瀏覽器裡；上方「↺ 從角色設定重玩」連按兩次可以重來。和 A 版、正式遊戲都分開。
- 這是測試用的暫時版本，測完會移除。
