# Sora One · 曦環城入口 A 版試玩預覽

直接開啟：**https://soraone2026.github.io/sora-halo-preview/**

- 這是 Sora One 遊戲的一段試玩預覽（單一 HTML 檔，`index.html`）。不需要登入，也不需要伺服器；圖片和 three.js 都已內嵌，可以離線開。
- 存檔只在你自己的瀏覽器裡，從 1 B 開始；頁面上方「↺ 重玩這段」連按兩次可以重來。和正式遊戲、其他人的存檔完全分開。
- 試玩範圍：點上方「世界」→ 星際城市「曦環城」。
- 手機和電腦都可以玩。第一次開啟有幾秒的進場動畫和 3D 載入。
